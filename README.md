# Découverte Audio — Demant

Application mobile de préparation des entretiens de découverte pour Frédéric Combeau.

## Fonctionnalités
- Deux profils : propriétaire de centre auditif et responsable de centrale/groupement
- 13 thématiques et questions de découverte, approfondissement, enjeux et projection
- Recherche, cartes dépliables, relances universelles
- Application statique, sans compte ni stockage de données clients

## Utilisation
Ouvrir `index.html` dans un navigateur, ou consulter le site GitHub Pages après activation.

## Déploiement GitHub Pages
Dans **Settings → Pages**, sélectionner **Build and deployment → Source: GitHub Actions**. Le workflow `.github/workflows/pages.yml` déploie automatiquement les modifications de `main`.

> Le dépôt doit être public pour une publication GitHub Pages gratuite.
